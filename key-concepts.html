HTTP Basics

Key Concepts of HTTP

These six concepts explain the main parts of communication between a browser and a web server.

1. Client and Server

A client is the browser or application that requests information. A server receives the request, processes it, and sends a response. A browser and a web server work together whenever a person visits a website.

2. HTTP Request

An HTTP request is a message sent by a client to ask for a resource or action. It can include a method, a request target, headers, and sometimes a body containing data.

3. HTTP Response

An HTTP response is the server's reply to a request. It includes a status code, headers, and often a body with information such as an HTML document, an image, or application data.

4. HTTP Methods

Methods describe the action a client wants to perform. GET is commonly used to retrieve information, POST submits information, and methods such as PUT, PATCH, and DELETE are used to update or remove resources.

5. Status Codes

Status codes are three-digit numbers that summarize the result of a request. For example, 200 means the request succeeded, 404 means the requested resource was not found, and 500 indicates a server error.

6. HTTPS and TLS

HTTPS is HTTP protected by Transport Layer Security (TLS). TLS encrypts information while it travels between a client and server and helps the client verify the server's identity.

7. HTTP Headers

HTTP headers provide additional information about a request or response. They help the client and server understand details about the communication. For example, headers can identify the type of content being sent, provide information about the browser, or describe caching instructions.

8. Cookies

Cookies are small pieces of information that websites store in a user's browser. They help websites remember certain information between visits, such as login sessions and user preferences. Cookies are commonly used to support personalized website experiences.

9. HTTP Caching

HTTP caching allows browsers and other systems to temporarily save copies of website resources. When a resource is requested again, a cached copy may be used instead of downloading it again. This can reduce loading times and help save network resources.

10. APIs and JSON

An API allows different software applications to communicate with each other. Web APIs commonly use HTTP to send requests and receive information. JSON is a common data format used to organize and exchange information between a client and a server.
