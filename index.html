What is HTTP?

HTTP stand for Hypertext Transfer Protocol. It is an application-layer protocol that allows browsers and servers to exchange information. When you visit a website, your browser asks for resources and a server send them back.

HTTP can transfer HTML documents, images, CSS files, Javascript, and data used by web applications. HTTP is not a programming language; it is a set of rules for communication

How does a web page load?

1

Enter a web address

The browser identifies the website and the resource you want.

2

Send a request

The browser sends an HTTP request to the web server.

3

Recieve a response

The server replies with a status code and, usually, content.

4

Display the page

The browser may request more files, such as stylesheets and images.
