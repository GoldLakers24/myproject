What is HTTP?

HTTP stands for Hypertext Transfer Protocol. It is an application-layer protocol that allows browsers and servers to exchange information. When you visit a website, your browser asks for resources and a server sends them back.

HTTP can transfer HTML documents, images, CSS files, JavaScript, and data used by web applications. HTTP is not a programming language; it is a set of rules for communication.

How does a web page load?

1

Enter a web address

The browser identifies the website and the resource you want.

2

Send a request

The browser sends an HTTP request to the web server.

3

Receive a response

The server replies with a status code and, usually, content.

4

Display the page

The browser may request more files, such as stylesheets and images.

Key Terms

HTTP
Hypertext Transfer Protocol, the rules browsers and servers use to exchange web information.
Client
The browser or application that sends a request for information.
Server
The computer or software that receives a request and sends a response.
Request
A message from a client asking for a resource or action.
Response
A message from a server that reports the result and may include requested content.
HTTPS
HTTP protected with TLS encryption while information travels across a network.
